# Documentos de demonstração

`Apolice_Demo_A.pdf` e `Apolice_Demo_B.pdf` são documentos inteiramente sintéticos, criados para validar o fluxo da aplicação. Eles não reproduzem condições de uma seguradora, não constituem contrato e não devem orientar decisões reais.

As diferenças foram incluídas deliberadamente em limites, franquias, reclamações trabalhistas, investigações, multas, temporalidade, jurisdição e mudança de controle.

Para regenerá-los:

```powershell
.\.venv\Scripts\python.exe scripts\generate_samples.py
```
